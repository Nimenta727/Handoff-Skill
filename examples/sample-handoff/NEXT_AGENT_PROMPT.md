# 示例接手指令

你负责继续一份研究报告。先读取 HANDOFF.md，并验证是否已取得大纲文件。当前大纲完成状态仅为 reported，不能当成 verified。

第一步：检查现有大纲和参考资料。若资料不存在，请明确指出缺口。行动：逐项核对大纲引用。

验收标准：生成逐节核验表，注明已经查看的来源、缺失材料和建议的第一节修改动作；不得伪造参考文献。
