# 2026-11-20 20:03 (+08:00) — Handoff Skill V1.1

## 做了什么

将 V1.0 交接模板升级为轻量、可核验、按需展开的 V1.1 交接机制。

## 具体改动

1. SKILL.md 增加渐进式上下文加载、默认 1200 字符预算、增量更新、
   来源复核和默认无外部副作用的行为规范。
2. scripts/validate_handoff.py 扩展 V1.0/V1.1 兼容、可选 SHA-256、
   TASKS.json 字段与 DAG、--strict、--json 和更多敏感模式检测。
3. scripts/handoff_tools.py 增加 init / brief / diff / seal，显式 --renew。
4. tests/test_handoff_v11.py 增加预算、安全、依赖、差量和兼容性测试；
   保留旧测试；添加 GitHub Actions CI。
5. 增加 references/task-state.md、docs/context-budget.md、
   docs/open-source-research.md，并更新 schema/workflow/checklist/next-agent。
6. README.md 扩展为中文优先、英文可用的完整安装及使用指南。

## 兼容性与限制

保留 Quick、Full、Update 三种模式及全部九个原始标题。
旧版本清单仍可读取；只有新文件的可选字段需要额外校验。
压缩预算是字符数而非精准 Tokens；SHA-256 是完整性而非身份认证。
不自动运行模型调用、业务命令或对话监控。

## 验证

已添加自动测试与 GitHub Actions 工作流；是否通过要根据提交后的
实际 CI 结果确认，不能提前当成已完成的验证。

## 下一步计划

1. 检查提交后的 CI 测试状态并修复实际失败，逐次写入新的 routine。
2. 在 ChatGPT、Claude、Codex 等宿主测量真实 prompt tokens、调用次数、
   首次任务成功率，确保减少上下文不损害完整性。
3. 增强 update 冲突合并、任务变更的证据过期处理与人工授权的接手 hook。
